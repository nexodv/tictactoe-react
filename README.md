# TicTacToe

This repository contains the code for a React-based TicTacToe game. Made for an application to Full Stack at Brown, Fall '26.

## Credits

Based on the official [React TicTacToe Tutorial](https://react.dev/learn/tutorial-tic-tac-toe).

## Instructions

Prerequisites:
- Node.js
- npm

To run this program in your web browser:
```
git clone https://github.com/nexodv/tictactoe-react
cd tictactoe-react
npm install
npm start
```

## Own Contribution

Beyond the tutorial credited above, I implemented:
- A custom design
- A restart button
- A tie detection

I did not use any tutorials for these. Some of the design code was based on former personal projects.

## Learnings

There were no major challenges, since everything in the tutorial was self-explanatory to me based on my background in web development. I did indeed become more proficient in React, since I had not worked with it before.
